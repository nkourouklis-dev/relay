Αυτό το zip περιέχει ΜΟΝΟ ένα αρχείο: index.html

ΤΙ ΝΑ ΚΑΝΕΙΣ:
1) Βγάλε το index.html από το zip (Extract / Εξαγωγή).
2) Πήγαινε στον φάκελο του project σου: relay/public/
3) Αντικατέστησε το υπάρχον index.html με αυτό (πάτα Replace όταν ρωτήσει).
4) Τρέξε: npm run dev  (για τοπική δοκιμή) ή npm run deploy (για live).

Τι αλλάζει σε αυτή την έκδοση:
- Κουμπί "Διαγραφή project"
- Το "Καθυστερημένο" εμφανίζεται σαν badge πάνω σε open/accepted (όχι ξεχωριστό status)
- Επεξηγήσεις (helper text) κάτω από κάθε πεδίο/ενότητα
- Κουμπί "Παράδειγμα (MoM)" που γεμίζει το πεδίο capture με ένα δείγμα κειμένου
  πρακτικών συνάντησης (γενικό, χωρίς πραγματικά στοιχεία εταιρείας — ασφαλές
  να το δείξεις και εκτός εταιρείας).
